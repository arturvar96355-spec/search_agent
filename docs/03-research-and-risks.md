# 03. Исследование и риски

Легенда: **[проверено]** — нашёл в источнике; **[не проверено]** — гипотеза или слова из блогов,
нужна сверка с первоисточником или консультация юриста. Это не юридическая консультация.

## 1. Главный риск: автоматическая холодная связь
Это ядро идеи, и оно же самое опасное. Три независимых слоя ограничений.

### 1.1 Закон о рекламе (38-ФЗ, ст. 18)
- Рассылка рекламы по сетям электросвязи (телефон, SMS) допускается только с предварительного
  согласия адресата **[проверено по цитате в Гаранте и Хабре]**.
- Спорный момент: попадают ли под это мессенджеры и email. Позиция ФАС и практика неоднозначны,
  поправка ФАС о мессенджерах упоминалась, статус неизвестен **[не проверено]**.
- Спорно, является ли персональное письмо «рекламой» (оффер конкретной компании по её фактам),
  но формально предложение своих услуг неопределённому кругу — реклама. Решает юрист.
- Штрафы: для юрлиц порядка 100–500 тыс. руб. по ст. 14.3 КоАП **[не проверено, сверить с кодексом]**.
- Практическое следствие для дизайна: **одно персональное сообщение по публичному
  деловому контакту, понятный отказ («напишите нет»), чёрный список, никаких массовых серий**.

### 1.2 Персональные данные (152-ФЗ)
- Сбор и хранение контактов физлиц (в т.ч. ИП, мастера-одиночки) = обработка ПД. Нужны: оператор ПД,
  уведомление в РКН (когда требуется), хранение баз граждан РФ на серверах в РФ.
  В курсе есть гайд `7-43-RKN_152FZ_GUIDE` и чеклист `7-40` **[проверено в материалах курса]**.
- Следствие: БД и сервер в РФ; срок хранения лидов ограничен; возможность удалить по запросу.

### 1.3 Правила площадок
- **Telegram**: за рассылки незнакомым — спам-ограничения и бан. Цифры лимитов в блогах расходятся
  (5–10 писем незнакомцам в день для нового аккаунта, и т.п.) **[не проверено, официальных данных нет]**.
  Писать от личного аккаунта фрилансера через автоматику = риск потерять аккаунт, который нужен для работы.
- **WhatsApp** (сторонний неофициальный доступ) — известны баны номеров **[не проверено]**;
  официальный WhatsApp Business API требует шаблонов и согласия получателя.
- **Яндекс Карты / 2ГИС**: условия API Яндекса, по обсуждениям, запрещают сохранять данные за пределами
  временного кэша **[не проверено по первоисточнику]**. Парсинг карточек сайта без API нарушает
  пользовательское соглашение. Нужен выбор легальных источников (лицензированные API, открытые реестры).
- **Биржи фриланса**: как правило запрещают ботов и автоматические отклики **[не проверено]**.

### 1.4 Репутация
Спам-сообщение от лица фрилансера бьёт по его имени в нише. Один плохой текст про чужие недостатки
(«у вас нет сайта») — нормальный ход; выдуманный факт или навязчивость — нет.

## 2. Что из этого следует для продукта
1. Агент **готовит**, человек **подтверждает** отправку (минимум первые недели).
2. Разные уровни риска каналов; стартуем с самых безопасных:
   - публичный деловой email компании → риск ниже;
   - форма обратной связи на сайте → риск ниже;
   - Telegram/WhatsApp бизнеса, указанный в публичной карточке для связи → средний риск;
   - звонок → оставляем человеку.
3. Дневные лимиты, паузы, чёрный список, глобальный «стоп» (kill switch) встроены в код, а не в промпт.
4. Каждое утверждение в сообщении привязано к источнику; нет источника — нет утверждения.
5. Отдельный отправляющий аккаунт/домен, не личный аккаунт фрилансера.

## 3. Конкуренты и аналоги
Прямого готового сервиса «поиск → досье → контакт → диалог → бриф → звонок» для фрилансера по
поиску **не нашёл** **[не проверено, поиск был поверхностным]**. Найденные соседние классы:

| Класс | Примеры (найдено в поиске) | Что делают | Чего не делают |
|-------|---------------------------|------------|-----------------|
| Парсеры по картам/каталогам | Prodvigator, Parsing Plus | собирают базы компаний | не пишут, не ведут диалог, не делают досье |
| Парсеры объявлений | B2BHelp (Авито), от ~490 ₽/мес | лиды с площадок | то же |

| Холодные рассылки/CRM, SDR-ИИ (зарубежные) | **[нужно исследовать]** | автоматизируют аутрич | юридически другая среда |

## 4. Где позиция продукта потенциально сильна
- Узкая специализация: исполнитель, а не отдел продаж, фокус на малом бизнесе с видимыми «дырами»
  (нет сайта, нет записи, слабая карточка).
- Досье с проверяемыми фактами и готовый бриф к звонку важнее, чем «автоматические рассылки».
- Это отличает продукт от спам-инструментов и юридически безопаснее.

## 5. Открытые исследовательские задачи
1. Юрист: допустимость персонального первого письма, текст отказа, нужен ли РКН-статус оператора.
2. Первоисточники: условия API Яндекса и 2ГИС, лицензии.
3. Какие каналы реально дают ответы в вашей нише (эксперимент на 30–50 лидах вручную).
