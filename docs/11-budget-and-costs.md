# 11. Бюджет и расчёт затрат (максимально экономичный вариант)

Статус: **оценка по формулам, не по реальным прогонам** [не оценено на живых данных]. Цены моделей взяты из справочника
Anthropic на 2026-11-03 (за 1 млн токенов): Haiku 5.5 $0.10 вход / $0.50 выход (для запросов до 100 тыс. токенов),
Sonnet 5.5 $2 / $10, Opus 5.5 $4 / $20. Чтение из кэша промпта намного дешевле входа, пакетная обработка (Batch) даёт
скидку 50%. Перед решением сверить с актуальной страницей цен.

## 1. Главное про вашу подписку
**Claude Pro не включает доступ к API.** Pro даёт чат и Claude Code, API оплачивается отдельно в консоли разработчика
([Anthropic: why separate billing for API](https://support.claude.com/en/articles/9876003-i-subscribe-to-a-paid-claude-ai-plan-why-do-i-have-to-pay-separately-for-api-usage-on-console)).
Код друга ходит именно в API (ключ `ANTHROPIC_API_KEY`), поэтому подписка Pro его не питает.
Есть три способа получить «мозг» для агента, от самого дешёвого:

| Уровень | Как | Деньги | Плюсы | Минусы |
|---------|-----|--------|-------|--------|
| **L0** | Конвейер собирает и обогащает лиды, а тексты вы получаете партиями в чате Claude Pro (вставляете пакет досье, забираете черновики) | 0 ₽ сверх подписки | как ваш прежний архив, никаких ключей | ручная работа, не масштабируется, нет автоответов |
| **L1** | Claude Code в режиме `claude -p` на вашем компьютере по подписке | в рамках подписки и месячного кредита | автоматизируется, без отдельного ключа | по найденным материалам с 15.06.2026 такой режим считается отдельным месячным кредитом (около $20 по сторонним данным, не подтверждено официально), а условия для регулярной автоматизации нужно перепроверить **[не проверено]** |
| **L2** | Ключ API с оплатой по факту | порядка единиц долларов в месяц на старте (см. п.3) | стабильно, масштабируется | нужен ключ и способ оплаты, который принимает консоль Anthropic: **это ваша зона ответственности, обходных путей я не подсказываю** |

Рекомендация: начать с **L0** (бесплатно, сразу), параллельно проверить L1 и L2. Конвейер проектируем так, чтобы «мозг»
подключался как сменный модуль (файл-обмен для L0, вызов CLI для L1, API для L2).

## 2. Оценка расхода токенов на лид
| Шаг | Модель | Вход, ток. | Выход (с размышлением), ток. | Цена за операцию |
|-----|--------|-----------|------------------------------|------------------|
| Оценка лида (подходит ли) | Haiku 5.5 | ~1 500 | ~500 | ≈ $0.0004 |
| Черновик сообщения | Sonnet 5.5 | ~3 000 (часть кэшируется) | ~1 300 | ≈ $0.02 (≈ $0.01 с кэшем и пакетом) |
| Черновик на Haiku (дешёвый вариант) | Haiku 5.5 | ~3 000 | ~1 300 | ≈ $0.001 |
| Разбор ответа клиента | Haiku 5.5 | ~1 000 | ~300 | ≈ $0.0003 |
| Реплика в диалоге | Sonnet 5.5 | ~4 000 | ~600 | ≈ $0.014 |

Эти числа сильно зависят от того, сколько «размышляет» модель; уровень усилия (`effort`) выставляем `low`/`medium`, чтобы не платить за лишнее.

## 3. Сценарии на месяц (L2)
Допущения: 100 лидов в неделю = 400 в месяц, 60% проходят оценку, 10% отвечают, в диалоге 3 реплики.
| Сценарий | Оценка | Черновики | Ответы и диалог | Итого в месяц |
|----------|--------|-----------|-----------------|---------------|
| Всё на Haiku 5.5 | $0.2 | 240 × $0.001 = $0.3 | 40 × (0.0003 + 3 × 0.002) ≈ $0.3 | **≈ $1** |
| Оценка Haiku, тексты и диалог Sonnet 5.5 | $0.2 | 240 × $0.02 = $4.8 | 40 × (0.0003 + 3 × 0.014) ≈ $1.7 | **≈ $7** |
| Всё на Opus 5.5 | – | в 2 раза дороже Sonnet | – | ≈ $13 |
Вывод: **расход на API будет небольшим, ключевой вопрос не цена, а доступ и оплата.** Пакетная обработка (−50%) и кэш системного промпта
снижают расход ещё. Каждый лид без сообщения стоит доли цента.

## 4. Остальные статьи затрат
| Статья | Старт (экономично) | Когда понадобится платить |
|--------|--------------------|---------------------------|
| Компьютер вместо VPS | 0 ₽ (ваш ПК, работает, пока включён) | когда нужна работа 24/7 |
| Прокси для парсинга 2ГИС | 0 ₽ при малых объёмах с домашнего IP, **риск блокировки IP** | при росте объёма (платный мобильный РФ) [цена не оценена] |
| DaData | бесплатный тариф | лимиты по росту |
| Telegram-бот | 0 ₽ | – |
| Домен и почта для рассылок | отдельный бесплатный ящик, домен позже | перед сегментом C |
| Юрист | – | разовая консультация перед рассылками |
| Anthropic API | 0–$1–$7 в месяц (п.3) | по мере роста |
Итого на старте: **0 ₽ при L0 и до нескольких долларов в месяц при L2**; платные прокси, VPS и домен откладываются.

## 5. Как держать расходы под контролем
- лимит суммы в консоли Anthropic и дневной лимит запросов в коде;
- логирование стоимости каждого вызова (у друга уже есть таблица `spend`);
- дешёвая модель для отсева, дорогая только для текстов, которые идут в отправку;
- кэш системного промпта и пакетная обработка, где не нужна скорость.
