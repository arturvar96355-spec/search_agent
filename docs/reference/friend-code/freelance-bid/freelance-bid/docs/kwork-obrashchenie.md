# Кворк: блокировка откликов на месяц

## Коротко

Снять блокировку может только поддержка Кворка. Обходить её нельзя: новый
аккаунт с тех же устройства и IP площадки вычисляют, и тогда бан становится
постоянным, а вместе с ним теряются отзывы и рейтинг. Единственный рабочий
путь — обращение в поддержку.

Ниже готовый текст. Отправлять из личного кабинета: **Помощь → Написать в
поддержку** (или support@kwork.ru с того же адреса, на который оформлен
аккаунт).

## Что отправить

> Здравствуйте!
>
> Мой аккаунт [логин] ограничен в откликах до [дата] за передачу контакта в
> переписке с заказчиком.
>
> Признаю нарушение: в сообщении заказчику я указал контакт вне площадки.
> Правило про общение и оплату только внутри Кворка мне понятно, перечитал
> раздел пользовательского соглашения.
>
> Что уже сделано, чтобы это не повторилось:
> — из шаблонов ответов убраны все ссылки, телефоны, почты и упоминания
>   мессенджеров;
> — переписка и обсуждение задач ведутся только в чате площадки;
> — оплата — только через Кворк.
>
> Прошу рассмотреть возможность досрочно снять ограничение на отклики.
> До блокировки нарушений не было, заказы закрывал в срок.
>
> Если досрочное снятие невозможно — подскажите, пожалуйста, точную дату
> окончания ограничения, чтобы я планировал работу.
>
> Спасибо.

## Чего в обращении быть не должно

- Спора о том, было нарушение или нет. Контакт передан — это видно в переписке,
  отрицание только затягивает разбор.
- Требований и угроз уйти к конкурентам. Решение принимает живой модератор.
- Просьб «разбаньте, я больше не буду» без конкретики. Работает описание того,
  что изменилось в процессе.

## Что уже сделано в софте

Правило зашито в код, а не только в инструкцию для модели:

- `fbid/policy.py` — на площадках со строгими правилами (Кворк, Юду) из отклика
  вырезаются ссылки, телефоны, почты и ники мессенджеров;
- если чистить пришлось, отклик **не отправляется вообще**: обрезанная фраза
  выглядит как попытка обойти правила;
- `knowledge/sales-playbook.md`, раздел «Правила площадок» — модель сразу пишет
  текст без контактов, кейсы описывает словами;
- созвон на таких площадках предлагается средствами самой площадки, без номера
  в тексте.

Когда блокировка снимется и появится вход в аккаунт, останется добавить адаптер
`fbid/sources/kwork.py` по образцу `profi.py` — политика для него уже описана.
