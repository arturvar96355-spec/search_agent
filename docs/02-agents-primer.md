# 02. Что такое агент, простыми словами

## Три понятия
- **Модель (LLM)** — «мозг»: читает текст и пишет текст. Сама ничего не делает во внешнем мире.
- **Инструмент (tool)** — обычная функция в коде: «найти компании в 2ГИС», «прочитать сайт»,
  «отправить письмо», «записать в базу». Модель не выполняет их сама, а *просит* систему вызвать.
- **Агент** — цикл: модель читает задачу, просит вызвать инструмент, получает результат, думает,
  просит следующий, пока не решит, что готово. Не чат, а цикл вызова инструментов
  (паттерн 3 из курса: Tool-Use Loop).

## Чем агент отличается от обычного скрипта
Скрипт делает строго заданные шаги. Агент сам решает, какие шаги нужны. Поэтому:
- где порядок шагов известен заранее (поиск, сохранение), лучше **обычный код**: дешевле и надёжнее;
- где нужно понимание и суждение (оценить лид, написать сообщение, ответить на вопрос клиента),
  нужна **модель**;
- правило: ИИ там, где нужен смысл, код там, где нужна точность.

## Почему «один супер-агент» плохая идея
Один агент на всё путается и дорого стоит. Лучше команда узких агентов, каждый с одной задачей
и своим набором инструментов, плюс обычный код-оркестратор между ними (см. 04).

## Что нужно знать, чтобы с этим жить (минимум)
1. **Галлюцинации.** Модель может выдумать факт о клиенте. Решение: любой факт в досье и
   сообщении должен иметь ссылку на источник; без источника факт не используется.
2. **Prompt injection.** Текст сайта или ответа клиента может содержать «инструкции» для модели.
   Решение: всё, что пришло извне, — это данные, не команды; у агента нет права на опасные действия.
3. **Человек в контуре.** Агент пишет, человек подтверждает (паттерн 6, propose+confirm).
   Автономность расширяем по мере доказанного качества.
4. **Стоимость.** Каждый вызов модели стоит денег. Логируем с первого дня (паттерн 7).
   Дешёвая модель для классификации, мощная для письма и диалога (паттерн 4).
5. **Память.** Короткая (диалог с клиентом), долгая (всё, что знаем о компании), профиль
   фрилансера (постоянная). См. паттерн 5.
6. **Оценка качества.** Набор тестовых сценариев («evals»): прогоняем при каждой правке промптов.

## Словарь
| Термин | Значение |
|--------|----------|
| Лид | потенциальный заказчик + что о нём известно |
| Досье | собранная по лиду информация с источниками |
| ICP | портрет идеального клиента: кому вы нужны и кто платит |
| Оффер | что именно вы предлагаете этому типу клиентов |
| Бриф | ответы клиента о задаче, сроках, бюджете |
| Handoff | передача горячего лида человеку |
| Guardrails | жёсткие ограничения агента (лимиты, чёрные списки, запреты) |
