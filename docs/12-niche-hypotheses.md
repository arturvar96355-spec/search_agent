# 12. Выбор ниш: гипотезы и дешёвый эксперимент

Контекст: салоны, клиники, цветы «пока не приносят успеха». Это факт со слов владельца, **цифр нет** [нужны: сколько сообщений
ушло, каким каналом, сколько ответов, что отвечали]. Ниже гипотезы, а не выводы.

## 1. Почему эти ниши могли не сработать (гипотезы)
1. **Есть заменитель сайта.** Салоны и клиники живут в агрегаторах записи (YClients, Dikidi и подобные), Instagram/VK, картах.
   Страница записи уже есть, сайт добавляет мало, и владелец не видит выгоды.
2. **Высокая насыщенность предложениями.** Этим нишам пишет каждый веб-студент, письмо тонет.
3. **Низкий чек относительно усилий.** Сделка на 5 000 ₽ требует тех же созвонов, что на 50 000 ₽.
4. **Канал.** Если писали вручную в мессенджер незнакомым, ответы всегда низкие, независимо от ниши.

## 2. Критерии выбора ниши (чем выше, тем лучше)
| Критерий | Почему важен |
|----------|-------------|
| Клиенты ищут услугу через поиск (Яндекс/Google/карты) и сравнивают | сайт даёт заявки, а не «красоту» |
| Высокий средний чек услуги, ≥ 20 000 ₽ | сайт за 5–30 тыс. быстро окупается |
| Нет готового заменителя вроде агрегатора записи | сайт закрывает реальную дыру |
| Владелец доступен и сам принимает решение | не нужно согласовывать |
| Мало конкурирующих веб-студий в этой нише | меньше шума |
| Контакт можно найти (телефон, мессенджер, почта) | иначе некому писать |

## 3. Кандидаты для проверки (гипотезы, ранжирование приблизительное)
| Ниша | Почему может сработать | Риск |
|------|------------------------|------|
| Ремонт и отделка квартир, бригады | высокий чек, спрос из поиска, часто только карточка и авито | много «авито-бригад», низкая платёжеспособность части |
| Грузоперевозки, переезды | поиск, высокая цена заказа, часто без сайта | конкуренция агрегаторов |
| Монтаж: окна, двери, потолки, кондиционеры | высокий чек, сравнение по сайтам | мелкие подрядчики без бюджета |
| Юристы, бухгалтеры, кадастровые услуги | доверие, чек, сайт нужен для репутации | жёсткая конкуренция студий |
| Малые производства B2B (металл, мебель на заказ, МАФ) | как «Стрела»: закупщик проверяет по сайту | длинный цикл решения |
| Аренда спецтехники, эвакуаторы | заказы из поиска | сезонность |
| Автошколы, репетиторские центры, частные школы | родители ищут и сравнивают | запись через агрегаторы |
| Фото/видео-услуги, event, свадебные | портфолио = сайт | много Instagram-портфолио |
| Автосервисы и шиномонтаж (были в прежнем архиве) | поиск, 2ГИС | запись по телефону, низкий интерес к сайту [проверить по вашим данным] |

## 4. Дешёвый эксперимент (чтобы не гадать)
1. Выбрать **5 ниш** из таблицы (минимум 3 новых), в каждой **20 лидов без сайта** из 2ГИС (сегмент A).
2. Одно и то же сообщение по структуре, адаптированное под нишу, **один канал и одинаковый темп**.
3. Считать на каждую нишу: найдено, написано, ответили, интерес, созвон.
4. Правило остановки: ниша с 0 ответов из 20 откладывается, ниша с ≥ 2 ответами из 20 получает ещё 60 лидов.
5. Результат фиксировать в таблице конвейера: `niche`, `segment`, `channel`, `sent`, `replied`, `call`.
Ориентир по курсу: ответы 10–15% на хорошо персонализированные сообщения **[не проверено]**; ваши 5% лидов до работы это отдельная метрика.

## 5. Дополнительные идеи
- **Демо-макет под лид**: перед сообщением агент собирает страницу-превью на реальных данных лида (название, адрес, услуги, отзывы из 2ГИС)
  и шлёт ссылку. Это сильнее слов и совпадает с принципом вашего сайта «макет сразу на ваших фактах». Отнесён в фазу 3.
- **Сегмент C (агентства)** не зависит от ниши клиента: он продаёт ваши услуги их клиентам.
