- Шпаргалка «лучший вход» по каждому агентству и правило follow-up (через 3 рабочих дня).

## Правила, зафиксированные владельцем
- **Про цену:** не писать «без абонентки / без подписки / 0 ₽» — неверно и риск по ФЗ «О рекламе».
  Реальная модель: $1200 разово + $150/мес поддержка. **В первом письме цену не называть** — она для созвона.
- **Про тон:** письма нарочно разные по длине и структуре (одинаковый скелет распознаётся сразу).
  В личный канал владельца — по имени; на общий ящик — без имени.
- **Подпись:** Менеджер Uniqore · uniqore.ru · +7 961 649-51-07 · TG: @UniqoreManager
- **Частичные конкуренты** (своя разработка/боты) помечены ⚠ — им не предлагать white-label ботов,
  только кастомные CRM и обмен клиентами.

## Что из этого стоит забрать в код (бэклог режима partners)
1. **Пометка «чей контакт»** — сейчас модель различает тип email (`partner/personal/sales/general`),
   но не помечает телефоны и Telegram (личный владельца / общий офисный / чат агентства).
   Это ключевое для аутрича — стоит добавить пометку и для них.
2. **«Лучший вход»** (`best_channel`) — вычислять рекомендацию: личный TG > партнёрская форма >
   личный email > общий email > офисный телефон. Сейчас есть только `best_email`.
3. **Партнёрская программа** — уже есть `has_partner_page` + `partner_page_url`; в ресёрче видно,
   что это самый конверсионный вход (loud-agency.ru/partnership, up-advert.ru/partners).
4. **ФИО владельца/ЛПР** — в ресёрче есть у большинства (ИП + ИНН). Для агентств это можно тянуть
   через DaData тем же `enrich.py`, что и для клиентов (ИНН → руководитель).
5. Сигнал «частичный конкурент» уже покрыт `red_flags: конкурент` — совпадает с ручными ⚠-пометками.
