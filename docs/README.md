# Search Agent — AI-агент поиска клиентов для фрилансера

Статус: **фаза планирования (черновик v0.1)**. Кода нет, это намеренно.

## Идея в одном абзаце
Фрилансер один раз рассказывает агенту, что умеет и кому помогает. Агент сам находит
потенциальных заказчиков на разных площадках, собирает на каждого досье, связывается,
ведёт диалог, собирает бриф и доводит до созвона. Фрилансер получает контакты и полное
досье, и на первом звонке уже знает о клиенте и его проекте всё. Позже продукт можно
продавать другим фрилансерам.
