# 10. Пошаговые инструкции для ручных действий

Правило сопровождения: у каждого ручного шага есть **зачем**, **что нажать**, **что должно получиться** и **как проверить**.
Если что-то выглядит иначе, присылайте скриншот, не пытайтесь угадывать. Интерфейсы чужих сервисов меняются, поэтому названия
кнопок могут отличаться от описанных здесь. Секреты (токены, ключи, пароли) **никогда не отправляйте в чат** и не кладите в Git.

Стартуем **локально на вашем компьютере (Windows)**, без VPS и без платного прокси: на небольших объёмах этого достаточно,
и это ничего не стоит. VPS и прокси подключим, когда объём вырастет и появятся деньги.

## Шаг 1. Установить Python 3.12
Зачем: код друга написан на Python 3.12.
1. Откройте https://www.python.org/downloads/windows/ и скачайте установщик Python **3.12.x** (Windows installer 64-bit).
2. Запустите. **На первом экране внизу поставьте галочку «Add python.exe to PATH»** (без неё дальнейшие команды не сработают).
3. Нажмите **Install Now**, дождитесь «Setup was successful», закройте.
4. Проверка: нажмите клавишу Windows, наберите `PowerShell`, откройте, введите `python --version` и Enter.
   Должно появиться `Python 3.12.…`. Если пишет, что команда не найдена, пришлите скриншот.

## Шаг 2. Создать Telegram-бота
Зачем: через него агент будет присылать вам лиды, черновики и отчёты.
1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите **Start**.
2. Отправьте `/newbot`.
3. Он спросит **название** (любое, например `Kovagor Leads`), затем **username**: латиницей, обязательно с `bot` на конце
   (например `kovagor_leads_bot`). Если занято, придумайте другое.
4. BotFather пришлёт **токен**: длинная строка вида `1234567890:AA...`. Это пароль к боту. Скопируйте его в
   блокнот, **в чат мне не присылайте**.
5. Откройте своего бота по ссылке из сообщения и нажмите **Start**.

## Шаг 3. Узнать свой Telegram ID
Зачем: чтобы бот слушался только вас.
1. Найдите **@userinfobot**, нажмите **Start**.
2. Он ответит числом в строке `Id:`. Запишите это число (оно не секретное, но личное).

## Шаг 4. Доступ к модели (Claude API) — ждём вашего ответа на В7
Нужен ключ и способ оплаты. Пока вы не напишете, как собираетесь получать доступ, этот шаг не делаем.
Ключ, как и токен бота, мне в чат не отправляется: я скажу, куда его вставить на вашем компьютере.
